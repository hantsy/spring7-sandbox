# Spring 7 Cookbook

Spring 7 retains Java 17 as a baseline but incorporates the new features from Java 25 (LTS). It aligns with the newest Jakarta EE 11 specification and updates the components to the latest version.

* Hibernate ORM 7
* Hibernate Validator 9
* Jackson 3
* Tomcat 11
* Kotlin 2 Refinement
* JUnit 6
